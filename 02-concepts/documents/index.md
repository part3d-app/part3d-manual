# Documents

A **Document** is one design. It holds everything you made for that object: its sketches, planes, solids, and the [History](../features-and-history/index.md) of Features that builds them. On disk it is a `.part3d` file.

You don't have to read this page to use Part3D. It just names the thing the rest of the manual keeps talking about.

## What's in a Document

- **Sketches**: the flat drawings your solids start from. See [Sketches](../sketches/index.md).
- **Planes**: the three Origin Planes, plus any Construction Planes you add. See [Planes](../planes/index.md).
- **Solids**: the 3D bodies you have built. See [Solids](../solids/index.md).
- **The History**: the ordered list of Features that makes the solids.

Save a Document and you save all of it, including the History, so you can come back later and change an early step.

## Where Documents live

The **Documents** screen lists your Documents. Tap **New Document** to start an empty one named **Untitled**, or tap an existing one to open it in the Editor. To rename the open Document, tap its name in the toolbar. Tap the save button (the floppy disk) to save it. The first time you save a Document, Part3D asks for its name.

> [!NOTE]
> **On Mac:** press ⌘S to save.
